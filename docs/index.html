Office2PDF 可视化批量转换

Word / PPT / Excel / Markdown / PDF → PDF。页面本身是静态的，真正的转换在 GitHub Actions 的 Ubuntu 机器上跑 LibreOffice。

1 · 仓库与授权

Token 权限：经典 token 勾选 repo + workflow；细粒度 token 给 Contents: Read and write + Actions: Read and write。 Token 只存在你这个浏览器里（localStorage，可随时清除），不会发往 GitHub 以外的地方。

2 · 选择文件

点击选择 或把文件拖到这里
支持 .doc .docx .odt .rtf .ppt .pptx .odp .xls .xlsx .ods .csv .md .pdf — 可多选
单文件建议 ≤ 20 MB（浏览器 + Contents API 双重限制）
    选择文件后即可开始
    流程：浏览器用你的 token 把文件提交到仓库的 inbox/<job>/ → 触发 convert 工作流 → Actions 里的 LibreOffice 转成 PDF 提交到 outbox/<job>/ → 页面轮询完成后直接下载。 一次作业通常 1–3 分钟。
