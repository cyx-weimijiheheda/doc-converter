Office2PDF 可视化批量转换

Word / PPT / Excel / Markdown / PDF → PDF。默认走公开服务：打开就能用，不需要 GitHub 账号、不需要 token。

1 · 运行方式

填好后所有访客零配置直接用
这就是为「让所有人都能用」准备的那条路：把 server/ 部署成一次（Docker / Hugging Face Space / 自己的 VPS）， 之后任何人打开本页拖文件即可转换——不用 GitHub 账号，不用 token，文件也只发往你自己部署的这台服务。 地址会存进本机 localStorage，也可用 ?api= 参数直接带过来。
这条路不用部署服务，但每个使用者都得自备 token（写权限在你仓库的 inbox/，所以不适合当公共入口）。 Token 权限：经典 token 勾 repo + workflow；细粒度 token 给 Contents: Read and write + Actions: Read and write。

2 · 选择文件

点击选择 或把文件拖到这里
支持 .doc .docx .odt .rtf .ppt .pptx .odp .xls .xlsx .ods .csv .md .pdf — 可多选
单文件上限以服务端配置为准（默认 40 MB），Actions 模式为 20 MB
    选择文件后即可开始
    流程（公开服务）：文件直接 POST 到你部署的转换服务 → 服务端 LibreOffice 转成 PDF → 浏览器拿回 PDF 并自动下载。 不经过 GitHub，不用登录。
